# MATLAB Workspace

This directory is the target home for MATLAB source, tests, examples, and toolbox-specific scripts.

## Transition status
The legacy MATLAB code currently remains at repository root.
All new MATLAB additions should be placed under `matlab/`.

## Planned end state
- `matlab/src/` for MATLAB algorithms
- `matlab/tests/` for MATLAB test suites
- `matlab/examples/` for MATLAB examples
